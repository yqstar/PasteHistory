# PasteHistory · 粘贴历史

轻量、原生的 macOS 菜单栏剪贴板工具。记录文本、图片和文件路径，将常用代码、链接和文字存为片段，随时搜索并粘贴。所有内容仅保存在本机。

## 能做什么

| 功能 | 用法 |
| --- | --- |
| 剪贴板历史 | 自动记录应用运行期间复制的文本、图片和文件路径，搜索后再次粘贴 |
| 常用片段 | 将代码、链接、回复模板、邮箱签名等文本单独保存，按标题和正文查找 |
| 快捷访问 | 使用全局快捷键打开选择器，也可以点击菜单栏图标访问最近内容 |
| 键盘与鼠标操作 | 方向键选择、Return 粘贴；也可使用底部操作按钮和顶部新建、关闭按钮 |
| 本地保存与备份 | 数据保存在本机，片段可导出为 JSON，并通过合并或替换方式导入 |

**历史记录有数量上限，片段单独保存。** 想长期保留的文本，可以从历史中“存为片段”；清空历史不会删除已保存片段。

## 开始使用

支持 **macOS 13 及以上**，Universal 安装包同时支持 Apple Silicon 和 Intel，无需另选架构。

1. 从 [最新 Release](https://github.com/yqstar/PasteHistory/releases/latest) 下载 Universal DMG。
2. 打开 DMG，将“粘贴历史”拖入 `Applications`，再从“应用程序”启动。
3. 在屏幕顶部菜单栏找到剪贴板图标。应用常驻菜单栏，不显示在 Dock 中，也不会在启动时自动弹出主窗口。
4. 如需自动粘贴，在“系统设置 → 隐私与安全性 → 辅助功能”中允许“粘贴历史”。未授权时仍可记录和搜索，执行“粘贴”后回到目标应用手动按 `⌘V`。

首次体验：启动后复制一段文字 → 在目标应用中放好输入光标 → 按 `⌃⌘P` → 选择记录 → 按 `Return` 或点击“粘贴”。

当前构建使用 ad-hoc 签名，尚未经过 Apple 公证；首次启动如被系统拦截，请在系统设置的“隐私与安全性”中查看并允许打开。

## 日常使用

### 找回复制过的内容

1. 按 `⌃⌘P`，或从菜单栏点击“历史选择器”。打开后可直接输入搜索关键词。
2. 使用 `↑`、`↓` 或鼠标选择记录。文本可按正文搜索，文件可按路径搜索，也可输入“文本”“图片”“文件”筛选类型。
3. 按 `Return`、点击底部“粘贴”或双击记录，内容会写回剪贴板，并尝试粘贴到打开选择器前的应用。

搜索不区分英文大小写，会检查完整文本内容，列表中的截断预览不影响搜索。按 `⌘F` 可返回搜索框并选中已有关键词；点击搜索框右侧的清除按钮可恢复完整列表。

底部的垃圾桶按钮和 `⌘⌫` 会删除当前记录；`Esc` 或右上角关闭按钮可收起选择器。切换到其他应用时选择器也会收起。

### 保存与编辑常用片段

| 场景 | 操作 |
| --- | --- |
| 从历史保存 | 在历史选择器中选中文本，点击“存为片段”或按 `⌘S` |
| 新建片段 | 按 `⌃⌘S` 打开片段选择器，点击“新建片段”或按 `⌘N` |
| 查找并粘贴 | 按标题或正文搜索，选择后按 `Return` 或点击“粘贴” |
| 编辑片段 | 选中片段，点击底部“编辑”或按 `⌘E` |
| 删除片段 | 选中片段，点击垃圾桶按钮或按 `⌘⌫` |

编辑器中的标题可以留空，保存时会根据正文第一条非空行自动命名；正文不能为空，并保留原有换行与缩进。保存相同正文时会提示已有片段，避免重复创建。

关闭有修改的编辑器、切换编辑内容或退出应用时，会提示“保存 / 放弃 / 取消”。保存失败时会保留当前草稿，便于继续修改或重试；草稿不等同于已经保存的片段。

片段用于保存文本。图片和文件记录不能通过“存为片段”保存，该按钮会在不适用时禁用；搜索无结果时，粘贴、删除和编辑等依赖选中项的操作也会禁用。

### 从菜单栏快速访问

点击剪贴板图标可以直接访问最近的 **5 条历史**和 **3 条片段**，点击具体内容即可恢复并尝试粘贴。更多内容放在“其余历史 / 其余片段”子菜单中，也可点击分组标题打开可搜索的选择器。

“设置…”和“退出”均位于菜单底部。关闭选择器只会收起窗口，应用会继续记录；需要停止运行时请使用“退出”。

## 快捷键

`⌃` 表示 Control，`⌘` 表示 Command，`⌥` 表示 Option，`⌫` 表示 Delete。

| 操作 | 默认快捷键 | 生效位置 |
| --- | --- | --- |
| 打开 / 收起历史选择器 | `⌃⌘P` | 全局，可在设置中修改 |
| 打开 / 收起片段选择器 | `⌃⌘S` | 全局，可在设置中修改 |
| 选择上一条 / 下一条 | `↑` / `↓` | 历史或片段选择器 |
| 粘贴选中内容 | `Return` | 历史或片段选择器 |
| 定位搜索框并选中关键词 | `⌘F` | 历史或片段选择器 |
| 关闭选择器 | `Esc` | 历史或片段选择器 |
| 删除选中项 | `⌘⌫` | 历史或片段选择器 |
| 将文本存为片段 | `⌘S` | 历史选择器 |
| 新建 / 编辑片段 | `⌘N` / `⌘E` | 片段选择器 |
| 打开设置 | `⌘,` | 菜单栏菜单展开时 |
| 退出应用 | `⌘Q` | 菜单栏菜单展开时 |

底部操作按钮和顶部新建、关闭按钮的工具提示会显示对应快捷键。新建、编辑等操作只在所属选择器内生效，不会接管其他应用里的同名快捷键。

## 设置与备份

从菜单栏打开“设置…”，修改会直接生效，无需额外点击保存。

| 分组 | 设置项 | 说明 |
| --- | --- | --- |
| 快捷访问 | 登录时启动 | 登录 macOS 后自动运行；建议先将应用放入“应用程序”再开启 |
| 快捷访问 | 历史 / 片段选择器 | 点击当前快捷键开始录制，按 `Esc` 取消，点击“恢复默认”恢复原组合 |
| 数据管理 | 历史条数 | 默认 **100 条**，范围 **10–500 条**；超出上限后移除列表末尾的较旧记录 |
| 数据管理 | 历史清理 | 确认后清空历史及其图片文件，保留已保存片段 |
| 数据管理 | 片段备份 | 导入或导出 JSON 文件，用于备份和手动迁移片段 |
| 版本与更新 | 版本记录 / 检查更新 | 离线阅读随应用附带的说明，或手动查询 GitHub 新版 |

录制快捷键时，组合需包含 `⌘`、`⌥`、`⌃` 中至少一个；如提示被占用，请换一个组合。降低历史条数上限也会立即清理超出的记录。

### 导出与导入片段

导出：在“数据管理 → 片段备份”点击“导出…”，选择保存位置。默认文件名为 `PasteHistory-snippets.json`，包含已保存片段的标题、正文和已有的独立快捷键配置。

导入：点击“导入…”，选择 JSON 文件，再选择导入方式：

| 方式 | 对现有片段的影响 |
| --- | --- |
| 合并导入 | 按 UUID 识别同一片段并更新，加入新片段，保留其他已有片段 |
| 替换全部 | 用导入的片段替换当前片段集合；建议先导出一份备份 |

导入会校验正文和快捷键配置，忽略部分重复项，并显示新增、更新或忽略的数量。片段备份不包含剪贴板历史、图片、登录启动设置或两个选择器的全局快捷键。

片段支持携带独立全局快捷键，触发后可直接粘贴正文。当前编辑器不提供该快捷键的录制入口，需通过 JSON 配置并导入；格式见 [开发说明](docs/DEVELOPMENT.md#代码片段格式)。发生注册冲突时，列表会显示冲突提示，仍可通过选择器正常粘贴。

### 更新应用

1. 在设置中点击“检查更新…”，查看新版本及发布说明。
2. 点击“下载新版…”下载 Universal DMG，也可以直接访问 [Release 页面](https://github.com/yqstar/PasteHistory/releases/latest)。
3. 从菜单栏退出当前应用，用新版替换“应用程序”中的旧版，再重新启动。

历史和片段存放在应用包之外，替换应用会保留原有数据。应用不会自动安装更新。

## 数据与隐私

数据目录为 `~/Library/Application Support/PasteHistory/`。可在 Finder 中使用“前往文件夹…”打开：

```text
PasteHistory/
├── history.json       # 文本、文件路径和图片元数据
├── snippets.json      # 已保存的片段
├── history.json.bak   # 历史数据的上一版备份（有上一版时生成）
├── snippets.json.bak  # 片段数据的上一版备份（有上一版时生成）
└── images/            # 复制过的图片，保存为 PNG
```

- 内容以明文保存在本机，不上传，不提供云端同步。复制过的敏感内容请及时清理。
- 文本按纯文本保存与恢复，不保留原应用的富文本排版；文件记录保存的是路径，不是文件副本，原文件仍需存在于对应位置。
- 应用会跳过带有 `concealed` 隐藏标记的剪贴板内容，但不会自动识别所有密码或敏感信息。
- 主数据文件损坏或缺失时会尝试读取备份，损坏文件会改名保留并提示。自动备份用于故障恢复，不是完整的历史版本或撤销机制。
- 只有手动检查更新时才会请求 GitHub；请求不包含剪贴板或片段内容。日常记录、搜索和粘贴无需联网。

## 常见问题

<details>
<summary>启动后没有窗口，也没有 Dock 图标？</summary>

这是菜单栏应用。点击屏幕顶部的剪贴板图标，或按 `⌃⌘P` / `⌃⌘S` 打开选择器即可。应用运行后，之后复制的内容才会被记录。

</details>

<details>
<summary>能找到记录，但没有自动粘贴？</summary>

先确认目标应用中有可粘贴的位置，并将输入光标放好。执行“粘贴”会先把内容写回剪贴板，可以回到目标应用手动按 `⌘V`。

自动粘贴还需要辅助功能权限；未授权时，到系统设置中允许“粘贴历史”。如果应用提示“安全键盘输入”开启中，请先使用手动粘贴。系统或其他应用启用这一保护时，PasteHistory 会跳过模拟按键。

</details>

<details>
<summary>历史记录为什么变少了，或者某次复制没有出现？</summary>

历史默认只保留 100 条，可在设置中调整到 10–500 条。达到上限、降低上限、手动删除或清空历史都会移除记录；同样的文本或文件路径再次复制时会更新已有记录的位置。

应用退出期间不会记录，空白文本和带隐藏标记的内容会跳过。剪贴板通过定时检查读取，连续极快地复制多项时，部分中间内容可能来不及记录。长期需要的文本请单独保存为片段。

</details>

<details>
<summary>全局快捷键不生效怎么办？</summary>

先从菜单栏打开选择器，确认应用正在运行，再进入“设置 → 快捷访问”录制其他组合。如果组合被系统或其他应用占用，会提示更换；也可以尝试“恢复默认”。

</details>

<details>
<summary>移动应用后，登录启动失效了？</summary>

登录启动配置会记录开启时的应用路径。请从新的位置打开应用，在设置中先关闭、再开启“登录时启动”，以更新路径。

</details>

## 从源码构建

项目使用 Swift / AppKit，无第三方依赖。需要 macOS 和 Xcode Command Line Tools；尚未安装时运行 `xcode-select --install`。

```bash
git clone https://github.com/yqstar/PasteHistory.git
cd PasteHistory
bash build.sh
open build/PasteHistory.app
```

`build.sh` 会生成 Apple Silicon / Intel 通用应用，并进行 ad-hoc 签名。

| 命令 | 用途 |
| --- | --- |
| `bash test.sh` | 运行数据、搜索、快捷键注册与更新检查逻辑测试 |
| `bash test-ui.sh` | 在 macOS 图形会话中运行原生界面回归测试 |
| `bash screenshots.sh` | 使用真实界面和临时示例数据生成深浅色截图 |
| `bash make-dmg.sh` | 将构建好的应用打包为 `build/PasteHistory.dmg` |

项目结构、数据格式、截图流程与自动发布配置见 [开发说明](docs/DEVELOPMENT.md)。
